# Instagram Reel Cover Correction

## Keep the original until its replacement is live

- Never delete a published Reel as the first step of changing its cover.

- Treat the published Reel as the only copy until a replacement with the new cover is published and verified live.

- Delete the original only after the user confirms that exact post and the replacement is verified live with the intended cover.

## Repost with a cover through the linked connector

- Change a Reel cover by publishing a replacement Reel with the new cover attached, not by editing the published Reel.

- Use the Instagram connector to publish the replacement, with its cover option and its frame choice for the thumbnail.

- Check the replacement after publishing and confirm the cover, the video, the caption and the account before touching the original.

## Hold when the connector is not linked

- Do not delete the original when the Instagram account is not linked, because the connector route for a covered repost is not available.

- Link the account through Meta Accounts Center first, or repost from the Instagram mobile app with the cover file, and keep the original live until that replacement is verified.

- If a cover fails to apply on a replacement, stop and keep the original live and report the failure instead of deleting the original to try again.

- Use the Instagram website only to edit a caption or to delete a post the user confirmed, because the website cannot change a Reel cover after publishing and a website video upload does not publish as a proper Reel.

## Available connectors

- [Instagram](/opt/hatch/connectors/instagram/CONNECTOR.md) for publishing a Reel with a cover and for checking whether the account is linked.

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Alternatives for better results

- Publish the replacement first and compare its cover with the intended design before deleting anything.

- Keep the original video file and cover file under `~/workspace/` until the replacement is verified, so a failed repost can be tried again without losing the source.
